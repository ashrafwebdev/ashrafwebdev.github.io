SMA Campus Suite

Active

A full school/college/university management backend covering the entire institutional pipeline — admission enquiries (CRM-style lead tracking), enrollment, academics, daily attendance, exams & results, fees & finance, hostel, transport, library, certificates, and HR & payroll, plus an admin-editable public campus page. FastAPI + SQLAlchemy + Alembic on the backend, React + TypeScript + Vite frontend, deployed and live with real invariants enforced server-side (fee balances computed from payments rather than a running total, room/route/seat capacity checks, a leave request that can only be decided once).

Video Correction Desktop App

Active

A lightweight Windows desktop client (Python + Tkinter) that wraps a backend "video correction" API — pick a file, upload it on a background thread so the UI never freezes, and see the result. Ships with a mock Flask backend implementing the same API contract, so the whole thing runs end-to-end with zero proprietary code. Demonstrates a pattern I use often: a thin, native-feeling client in front of someone else's service.
