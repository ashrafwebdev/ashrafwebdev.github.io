Control flow and functions

Go · part of the free zero-to-hero guide

Go has only one looping construct, for, which covers what other languages split into for, while, and infinite loops depending on how many clauses you provide. There is no while keyword at all.

if statements can include an initializer clause, scoping a variable to just the condition and its branches, which is idiomatic for patterns like checking a map lookup's second return value.

Functions can return multiple values, which Go uses pervasively for the common pattern of returning a result alongside an error, rather than throwing exceptions.

main.go
package main

import "fmt"

func divide(a, b int) (int, error) {
	if b == 0 {
		return 0, fmt.Errorf("cannot divide %d by zero", a)
	}
	return a / b, nil
}

func main() {
	for i := 0; i < 3; i++ {
		if result, err := divide(10, i); err != nil {
			fmt.Println("error:", err)
		} else {
			fmt.Println("result:", result)
		}
	}
}
Key points
  • for is Go's only loop keyword; omitting all three clauses makes it an infinite loop.
  • An if initializer clause scopes a helper variable to just that if/else block.
  • Functions commonly return a value and an error as two separate return values.
  • Named return values are optional but can make short functions more self-documenting.
Try it yourself

Write a function safeSqrt(x float64) (float64, error) that returns an error for negative input, then call it in a for loop over a few sample values, printing results or errors.
