Arrays and objects basics

JavaScript · part of the free zero-to-hero guide

Arrays hold ordered lists of values, accessed by index starting at 0. Objects hold key-value pairs, accessed by key — use arrays when order matters and items are similar; use objects when you're modeling a single 'thing' with named properties.

Both are mutable by default — even a const array or object can have its contents changed, since const only prevents reassigning the variable itself, not mutating what it points to.

collections.js
const fruits = ["apple", "banana", "cherry"];
fruits.push("date"); // mutates the array, allowed even with const

const user = {
  name: "Yusuf",
  age: 30,
  isAdmin: false,
};
console.log(fruits[0], user.name, user["age"]);
Key points
  • Arrays: ordered, indexed from 0, use .length to get the count.
  • Objects: unordered key-value pairs, access via dot notation or bracket notation.
  • const prevents reassignment, not mutation — const arr = []; arr.push(1); is perfectly valid.
  • Nested structures (arrays of objects, objects containing arrays) are extremely common in real code.
