Arrays

Java · part of the free zero-to-hero guide

A Java array is a fixed-size, ordered collection of elements of a single type, declared with square brackets, such as int[] scores. Once created with new int[5], its length cannot change; if you need a resizable collection you reach for ArrayList instead, covered later.

Arrays are zero-indexed, and accessing an index outside the valid range throws an ArrayIndexOutOfBoundsException at runtime rather than silently producing garbage or a wrong value, which is a deliberate safety feature of the language compared to lower-level languages that let you read whatever memory happens to be there.

An array of a reference type, such as String[] names = new String[3], is initially filled with null in every slot, not empty strings; forgetting this and calling a method on an unassigned slot produces a NullPointerException at the point of use, not at array creation.

Multi-dimensional arrays are simply arrays of arrays, declared as int[][] grid = new int[3][3]. Because each inner array is independent, Java also supports jagged arrays where rows have different lengths, such as int[][] triangle = new int[5][] followed by allocating each row separately with a different size.

Arrays are passed to methods by reference (the array's contents can be mutated by the callee and the caller sees the change), but the array variable itself is still a normal reference: reassigning the parameter inside the method to a brand-new array does not affect the caller's original variable.

The java.util.Arrays class provides helpers for common operations that would otherwise require hand-written loops: Arrays.sort, Arrays.toString (and deepToString for nested arrays), Arrays.equals, Arrays.fill, and Arrays.copyOf for creating a resized copy of an existing array.

Scores.java
import java.util.Arrays;

public class Scores {
    public static void main(String[] args) {
        int[] scores = {88, 92, 75, 100, 60};
        Arrays.sort(scores);
        System.out.println(Arrays.toString(scores));

        int sum = 0;
        for (int s : scores) sum += s;
        System.out.println("Average: " + (sum / scores.length));
    }
}
Grid.java
import java.util.Arrays;

public class Grid {
    public static void main(String[] args) {
        int[][] grid = new int[3][3];
        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[r].length; c++) {
                grid[r][c] = r * 3 + c;
            }
        }
        System.out.println(Arrays.deepToString(grid));

        // Jagged array: row lengths differ
        int[][] triangle = new int[4][];
        for (int r = 0; r < triangle.length; r++) {
            triangle[r] = new int[r + 1];
            Arrays.fill(triangle[r], r);
        }
        System.out.println(Arrays.deepToString(triangle));
    }
}
NullSlotBug.java
public class NullSlotBug {
    public static void main(String[] args) {
        String[] names = new String[3];
        names[0] = "Amina";
        // names[1] and names[2] are still null, not ""

        for (String name : names) {
            // Throws NullPointerException on the second element
            System.out.println(name.toUpperCase());
        }
    }
}
Key points
  • Array length is fixed at creation time and is read via the .length field, not a method.
  • Out-of-bounds access throws ArrayIndexOutOfBoundsException rather than failing silently.
  • Reference-type arrays start filled with null, not empty values, in every slot.
  • Arrays are passed by reference, so mutating elements inside a method is visible to the caller, but reassigning the parameter is not.
  • Multi-dimensional arrays are arrays of arrays and can be jagged, with rows of different lengths.
  • java.util.Arrays offers sort, toString/deepToString, equals, fill, and copyOf.
  • For a resizable, growable list, use ArrayList instead of a raw array.

Then build a 5x5 jagged 2D array where row i has i+1 columns filled with the value i, print it with Arrays.deepToString, and add a check that skips any null entries before calling a method on an array of String.
