Filtering with AND/OR/IN/LIKE

SQL · part of the free zero-to-hero guide

Multiple conditions in a WHERE clause combine with AND (all must be true) and OR (at least one must be true); when mixing both, parentheses make evaluation order explicit and avoid subtle logic bugs, since AND binds tighter than OR by default.

IN checks a column against a list of values in one concise expression, replacing what would otherwise be a long chain of OR comparisons on the same column: WHERE category IN ('books', 'electronics').

LIKE performs pattern matching on text, using % to match any sequence of characters and _ to match exactly one character — WHERE name LIKE 'A%' finds every name starting with A.

query.sql
SELECT name, category, price
FROM products
WHERE category IN ('books', 'electronics')
  AND (price < 10 OR name LIKE 'Deluxe%');
Key points
  • AND requires every condition true; OR requires at least one; parentheses make precedence explicit.
  • IN checks a column against a list of values, replacing a long chain of OR comparisons.
  • LIKE performs pattern matching, with % for any sequence and _ for a single character.
  • Case sensitivity of LIKE depends on the database engine and column collation.
