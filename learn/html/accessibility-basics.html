Accessibility basics: alt text, labels, landmark roles

HTML · part of the free zero-to-hero guide

Accessibility (often shortened to a11y) means your page works for people using screen readers, keyboard-only navigation, or other assistive technology — not as an afterthought, but built in from the start, because most of it is just writing correct HTML.

Three habits cover most of the ground: meaningful alt text on every informative image, a <label> for every form input, and using semantic landmark elements (header, nav, main, footer) so assistive tech users can jump straight to the part of the page they need.

Good vs. bad alt text
<!-- Bad: unhelpful -->
<img src="chart.png" alt="image">

<!-- Good: describes the content -->
<img src="chart.png" alt="Sales grew 40% from January to June 2026">

<!-- Decorative image: empty alt, not missing alt -->
<img src="divider-swirl.png" alt="">
Key points
  • Alt text should describe the information conveyed, not just say "image" or "photo".
  • Decorative images get alt="" (empty) so screen readers skip them silently.
  • Every interactive element needs a keyboard-reachable, clearly labeled path — test by unplugging your mouse.
  • Landmarks (header/nav/main/footer) let screen reader users skip repeated navigation instantly.
Try it yourself

Go back through every page you've built so far and check: does every image have real alt text, and every input have a label? Fix any you find.
