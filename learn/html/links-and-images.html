Links and images

HTML · part of the free zero-to-hero guide

Builds on: Headings, paragraphs, lists

The <a> (anchor) tag creates a hyperlink using its href attribute. Links can point to other sites, other pages on your own site, or a spot further down the same page using an id and a # in the href.

The <img> tag embeds an image using src for the file path and a required alt attribute describing the image in words — screen readers read it aloud, and browsers show it if the image fails to load.

Not every href needs a full URL. A relative path like about.html or ../images/logo.png is resolved against the current page's location, which is why the same site can be moved between domains without rewriting every internal link — as long as the relative structure stays the same. An absolute path starting with /, like /about.html, always resolves from the site's root regardless of which page you're currently on.

Links that leave your site and open in a new tab (target="_blank") should almost always also carry rel="noopener". Without it, the newly opened page gets a live JavaScript reference back to your original tab (window.opener), which a malicious destination site could abuse to redirect your original tab to a phishing page while the user is looking at the new one — a real, documented attack technique known as tab-nabbing.

Images have their own performance dimension: width and height attributes on <img> aren't just for sizing — specifying them lets the browser reserve the correct space before the image file finishes downloading, preventing the rest of the page from jumping around as images pop in (a metric called Cumulative Layout Shift). For images that need to look sharp on both regular and high-density ("Retina") screens, or that should swap to a different crop on mobile, the srcset and sizes attributes let the browser choose the best file for the visitor's actual screen instead of always downloading one fixed image.

For images that themselves need to link somewhere, wrap the <img> in an <a> tag rather than trying to fake click behavior with CSS or JavaScript — it's simpler, keyboard-accessible by default, and works exactly the way every visitor already expects a link to work.

index.html
<a href="https://developer.mozilla.org">MDN Web Docs</a>
<a href="/about.html">About page (relative to site root)</a>
<a href="#section-2">Jump to Section 2</a>

<img src="logo.png" alt="Company logo" width="120">

<h2 id="section-2">Section 2</h2>
<p>You'll land here when the link above is clicked.</p>
safe external links and responsive images
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Opens in a new tab, safely
</a>

<!-- Browser picks the best file for the screen's pixel density -->
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1600.jpg 1600w"
  sizes="(max-width: 600px) 100vw, 800px"
  width="800" height="450"
  alt="A hiking trail at sunrise">
common mistake: an unsafe blank-target link
<!-- Risky: the new tab can access window.opener and
     redirect this original tab to a phishing page -->
<a href="https://untrusted-site.example" target="_blank">Click here</a>

<!-- Safer: always pair target="_blank" with rel="noopener" -->
<a href="https://untrusted-site.example" target="_blank" rel="noopener">Click here</a>
Key points
  • href can be an absolute URL, a relative path, or an in-page anchor (#id).
  • alt text is not optional for meaningful images — it's an accessibility requirement.
  • Decorative images that add no information can use alt="" (empty, not omitted).
  • Always pair target="_blank" with rel="noopener" to prevent tab-nabbing.
  • Set width and height on images to prevent layout shift while they load.
  • srcset/sizes let the browser choose the right image file for the visitor's screen instead of one-size-fits-all.
  • A relative path resolves against the current page's location; a path starting with / resolves from the site root.
Try it yourself

Add a navigation list of three links to your recipe page from the last lesson, including one that jumps to the Ingredients heading using an anchor link and one external link that safely opens in a new tab. Then add width, height, and a srcset with two sizes to one image, and use dev tools to confirm the browser picks a different file on a narrower viewport.
