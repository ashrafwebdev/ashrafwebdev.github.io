01 Zero stage

Syntax, variables, and control structures

PHP · part of the free zero-to-hero guide

PHP variables always start with a dollar sign ($name) and need no type declaration. PHP code lives inside <?php ... ?> tags, which can be embedded directly in an HTML file — the server runs the PHP and sends the resulting HTML to the browser. A file can contain many separate PHP blocks mixed with plain HTML; everything outside a PHP tag is sent to the browser verbatim.

Control structures — if/elseif/else, for, while, do...while, foreach — look similar to C-family languages, with curly braces marking blocks. foreach is the idiomatic way to walk any array, whether indexed or associative, and can destructure key and value at once with foreach ($arr as $key => $value).

PHP is loosely (dynamically) typed and performs automatic type juggling during comparisons and arithmetic, which is convenient but a frequent source of bugs. The loose equality operator == converts operands to a common type before comparing, so 0 == "abc" was historically true in older PHP versions and "1" == "01" is still true today; the strict equality operator === compares both value and type with no conversion, and should be the default choice unless you deliberately want juggling.

Arrays are PHP's single most important data structure and do double duty as both a list and a hash map — an ordered, mutable collection of key/value pairs where keys are automatically integers unless you supply strings. $fruit = ["apple", "pear"]; creates an indexed array with keys 0 and 1, while $ages = ["Amina" => 27, "Tom" => 31]; creates an associative array.

Comments use // or # for a single line and /* ... */ for multiple lines; whitespace outside of string literals is insignificant, but every statement must end with a semicolon — omitting one is one of the most common beginner mistakes and produces a parse error on the following line, which can be confusing to debug.

PHP 8 introduced the match expression as a stricter, more concise alternative to switch: match compares with strict (===) semantics, has no fall-through between arms, requires every arm to be handled (or throws an UnhandledMatchError), and evaluates directly to a value rather than requiring a break in every branch.

basics.php
<?php
$name = "Amina";
$age = 27;

if ($age >= 18) {
    echo "$name is an adult.";
} else {
    echo "$name is a minor.";
}
?>
loops_and_arrays.php
<?php
$scores = ["Amina" => 92, "Tom" => 81, "Lee" => 74];

foreach ($scores as $name => $score) {
    echo "$name scored $score\n";
}

// Classic for loop over an indexed array
$nums = [10, 20, 30];
for ($i = 0; $i < count($nums); $i++) {
    echo $nums[$i] . "\n";
}
?>
match_vs_switch.php (a common type-juggling gotcha)
<?php
$input = "0";

// Loose comparison: string "0" is falsy, easy to trip over
if ($input == false) {
    echo "This runs even though \$input is a non-empty string!\n";
}

// match() uses strict comparison and returns a value directly
$label = match ($input) {
    "0" => "zero as text",
    0    => "zero as int",
    default => "something else",
};
echo $label; // "zero as text" — no int/string coercion happens
?>
Key points
  • Every PHP variable starts with $ — this is not optional punctuation, it's part of the variable name.
  • PHP is loosely typed by default, though modern PHP supports optional type declarations on function parameters and return values.
  • Variable interpolation works directly inside double-quoted strings ("$name is...") but not single-quoted ones.
  • Every statement ends with a semicolon — a common early mistake is forgetting it, which throws off the parser on the next line.
  • Prefer === and !== over == and != to avoid surprising type-juggling bugs.
  • Arrays in PHP are ordered maps — the same construct handles both simple lists and associative dictionaries.
  • match (PHP 8+) is stricter and more predictable than switch: no fall-through, strict comparisons, and it returns a value.
  • foreach is almost always preferred over manual index loops for iterating arrays — it's clearer and works on both indexed and associative arrays.
Try it yourself

Write a PHP script with variables for a product name and price, and an if statement that prints a discount message if the price is over $50. Then build a small associative array of three products to prices, loop over it with foreach to print each one, and rewrite the discount check using match instead of if/else.
