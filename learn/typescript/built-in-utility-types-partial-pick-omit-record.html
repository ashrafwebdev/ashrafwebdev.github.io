Built-in utility types (Partial, Pick, Omit, Record)

TypeScript · part of the free zero-to-hero guide

TypeScript ships a set of generic utility types that transform existing types instead of requiring you to redefine them from scratch. Partial<T> makes every property optional — perfect for an 'update' function that only changes some fields.

Pick<T, Keys> and Omit<T, Keys> create a new type from a subset (or everything except a subset) of another type's properties. Record<Keys, ValueType> builds an object type mapping a set of keys to a consistent value type.

utilityTypes.ts
interface User {
  id: number;
  name: string;
  email: string;
}

function updateUser(id: number, changes: Partial<User>) { /* ... */ }

type UserPreview = Pick<User, "id" | "name">;
type UserWithoutId = Omit<User, "id">;
type UsersById = Record<number, User>;
Key points
  • Partial<T>: every property optional. Required<T>: the opposite, every property mandatory.
  • Pick<T, K> selects specific keys; Omit<T, K> excludes them — often used together across an app's types.
  • Record<K, V> is the idiomatic way to type an object used as a lookup map.
  • These utility types are just generics defined using features you already know — reading their source is a great learning exercise.
