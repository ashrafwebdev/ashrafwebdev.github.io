Working with files

C# · part of the free zero-to-hero guide

The System.IO namespace's File class offers simple static methods for common operations: File.WriteAllText, File.ReadAllText, and File.ReadAllLines cover most small-file needs in a single call.

For larger files or streaming, StreamReader and StreamWriter let you process a file line by line without loading it entirely into memory, and both implement IDisposable so they pair naturally with a using block.

File operations can throw exceptions like FileNotFoundException or UnauthorizedAccessException, so production file code typically wraps these calls in a try/catch alongside the resource-safe using pattern.

Program.cs
string path = "notes.txt";
File.WriteAllText(path, "First line\nSecond line\n");

using (var reader = new StreamReader(path))
{
    string? line;
    while ((line = reader.ReadLine()) != null)
    {
        Console.WriteLine($"> {line}");
    }
}
Key points
  • File.WriteAllText/ReadAllText are convenient for small, whole-file operations.
  • StreamReader/StreamWriter handle large files line by line without high memory use.
  • Both stream classes implement IDisposable and should be wrapped in a using block.
  • File I/O can throw; wrap it in try/catch when the file's existence or permissions aren't guaranteed.
