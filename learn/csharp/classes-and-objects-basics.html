Classes and objects basics

C# · part of the free zero-to-hero guide

A C# class groups fields and methods together, and objects are created from it with new. Properties (public string Name { get; set; }) are C#'s idiomatic way to expose state, offering the syntax of a field with the control of a method underneath.

Constructors initialize an object's state when created. C# also supports record types (record Person(string Name, int Age)), a concise syntax for immutable data-holding classes that automatically get value-based equality and a readable ToString.

The this keyword refers to the current instance, most often used inside a constructor to distinguish a field from a same-named parameter.

Program.cs
public class Book
{
    public string Title { get; set; }
    public int Pages { get; set; }

    public Book(string title, int pages)
    {
        Title = title;
        Pages = pages;
    }

    public string Summary() => $"{Title} ({Pages} pages)";
}

var book = new Book("Clean Code", 464);
Console.WriteLine(book.Summary());
Key points
  • Properties (get/set) are the standard way to expose an object's state in C#.
  • Record types give concise, immutable data classes with built-in value equality.
  • Constructors run automatically when an object is created with new.
  • this disambiguates a field from a constructor parameter of the same name.
