Arrays and lists

C# · part of the free zero-to-hero guide

Builds on: Classes and objects basics

A C# array (int[] scores = new int[5]) is fixed-size and zero-indexed, same as most C-family languages. Accessing an out-of-range index throws an IndexOutOfRangeException at runtime, and there is no way to grow or shrink an array once created — you must allocate a new one and copy elements over, which is exactly what Array.Resize does under the hood.

For a resizable collection, List of T from System.Collections.Generic is the standard choice, offering Add, Remove, Insert, and Contains methods and growing automatically as items are added. Internally a list is backed by an array that doubles in capacity when it fills up, so occasional resizes are amortized to still give roughly constant-time appends on average.

Multi-dimensional arrays come in two flavors: rectangular arrays (int[,] grid = new int[3,3]), where every row has the same length, and jagged arrays (int[][] jagged), which are arrays of arrays where each inner array can have a different length. Jagged arrays are generally preferred in C# because they're more memory-efficient when rows vary in size and integrate more naturally with the rest of the collection APIs.

Both arrays and lists implement IEnumerable of T, so they work seamlessly with LINQ (covered in a later lesson): operations like sorting, filtering, and aggregating can be written declaratively instead of with manual loops. A common beginner mistake is calling a LINQ method like OrderBy expecting it to sort in place — it doesn't; it returns a new sequence, leaving the original list untouched.

Removing items from a list while iterating it with foreach throws an InvalidOperationException, because the enumerator detects the collection was modified. The safe patterns are iterating backward with an indexed for loop, using RemoveAll with a predicate, or building a filtered copy with LINQ's Where and assigning it back.

For performance-sensitive scenarios, Span of T lets you work with a slice of an array without copying it, and collection expressions (int[] xs = [1, 2, 3], C# 12+) offer a unified, terser syntax for initializing arrays, lists, and other collection types.

Program.cs
int[] scores = { 88, 92, 75, 100, 60 };
Array.Sort(scores);
Console.WriteLine(string.Join(", ", scores));

List<string> names = new List<string> { "Amina", "Bilal" };
names.Add("Omar");
names.Remove("Bilal");
Console.WriteLine(string.Join(", ", names));
JaggedAndRemoval.cs
// Jagged array: each row can be a different length
int[][] triangle = new int[3][];
triangle[0] = new int[] { 1 };
triangle[1] = new int[] { 1, 2 };
triangle[2] = new int[] { 1, 2, 3 };

foreach (var row in triangle)
    Console.WriteLine(string.Join(" ", row));

// Safe removal while conceptually 'iterating': RemoveAll with a predicate
var numbers = new List<int> { 1, 2, 3, 4, 5, 6 };
numbers.RemoveAll(n => n % 2 == 0);
Console.WriteLine(string.Join(", ", numbers)); // 1, 3, 5
MutationMistake.cs
var items = new List<int> { 1, 2, 3 };

// WRONG: throws InvalidOperationException -- collection modified during iteration
// foreach (var i in items)
//     if (i == 2) items.Remove(i);

// RIGHT: iterate backward with an indexed loop
for (int i = items.Count - 1; i >= 0; i--)
{
    if (items[i] == 2) items.RemoveAt(i);
}

// ALSO RIGHT: OrderBy does not sort in place -- it returns a new sequence
var sorted = items.OrderBy(x => x).ToList();
Key points
  • Arrays have a fixed length set at creation; List of T grows and shrinks dynamically.
  • A List of T is backed by an array that doubles in capacity, giving amortized constant-time appends.
  • Jagged arrays (arrays of arrays) allow different row lengths; rectangular arrays require equal-length rows.
  • Array.Sort sorts in place; LINQ's OrderBy does not — it returns a new sequence.
  • Removing items from a list during a foreach throws; use RemoveAll or an indexed backward loop instead.
  • Both arrays and lists implement IEnumerable of T, so foreach and LINQ work on either.
  • Collection expressions ([1, 2, 3], C# 12+) offer a terser, unified initializer syntax.
Try it yourself

Create a List of int with 8 numbers, remove any values less than 10 using RemoveAll, sort the rest, and print the result joined by commas. Then build a small jagged array representing rows of increasing length (like the triangle example) and print each row on its own line.
