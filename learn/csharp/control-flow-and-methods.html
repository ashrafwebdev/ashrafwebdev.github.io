01 Zero stage

Control flow and methods

C# · part of the free zero-to-hero guide

Builds on: Syntax, variables, and types

C# supports if/else, for, foreach, while, do-while, and switch. The modern switch expression (C# 8+) returns a value directly using => arms and supports pattern matching on types, shapes, and ranges, not just constant values, which replaces many verbose if/else chains with something far more readable.

Pattern matching goes beyond switch expressions: is can test and cast in one step (if (shape is Circle c)), and switch arms can match on a type pattern, a property pattern ({ Age: >= 18 }), or combine several with and/or/not. This turns what used to require nested type checks and casts into a single declarative expression.

Methods are declared with an access modifier, a return type, a name, and parameters. C# supports optional parameters with default values, named arguments so callers can pass arguments out of order by name, and params arrays for a variable number of trailing arguments — three separate features that are often combined to design flexible APIs.

Parameters can be passed by reference with ref (the argument must already be initialized), by output with out (the method must assign it before returning, commonly seen in TryParse-style methods), or read-only-by-reference with in for large structs you don't want copied. Plain parameters, by contrast, are always passed by value — even reference types, where it's the reference itself that's copied, not the object it points to.

foreach is the idiomatic way to iterate any collection implementing IEnumerable, and is generally preferred over an index-based for loop unless you specifically need the index or need to modify the collection while iterating (which foreach forbids and throws an InvalidOperationException for).

Local functions — a method declared inside another method — are useful for small helper logic that only makes sense in one place, and unlike a separate private method they can capture variables from the enclosing method directly, similar to a closure.

Program.cs
static string Categorize(int score) => score switch
{
    >= 90 => "A",
    >= 80 => "B",
    >= 70 => "C",
    _ => "F"
};

int[] scores = { 95, 82, 61 };
foreach (var s in scores)
{
    Console.WriteLine($"{s} -> {Categorize(s)}");
}
PatternsAndParams.cs
static string Describe(object shape) => shape switch
{
    Circle { Radius: <= 0 } => "invalid circle",
    Circle c => $"circle, area {c.Radius * c.Radius * Math.PI:F1}",
    Square s when s.Side > 10 => "large square",
    Square => "square",
    null => "nothing",
    _ => "unknown shape"
};

static int Sum(params int[] numbers)
{
    int total = 0;
    foreach (var n in numbers) total += n;
    return total;
}

Console.WriteLine(Sum(1, 2, 3, 4)); // params lets any number of args
RefOutTryParse.cs
// out parameters: the classic TryParse pattern
if (int.TryParse("42", out int parsed))
    Console.WriteLine($"Parsed: {parsed}");

// ref parameters: the argument must already be assigned
static void Double(ref int n) => n *= 2;
int value = 21;
Double(ref value);
Console.WriteLine(value); // 42
Key points
  • Switch expressions with relational patterns (>= 90) replace long if/else chains.
  • Property patterns and type patterns let a single switch arm match a shape and its data at once.
  • Optional parameters, named arguments, and params arrays make method calls more flexible and readable.
  • out parameters must be assigned by the method; ref parameters must already be assigned by the caller.
  • Ordinary parameters are always passed by value, even for reference types — it's the reference that's copied.
  • foreach is the idiomatic way to iterate collections implementing IEnumerable, but disallows mutating the collection mid-iteration.
  • Local functions can capture enclosing variables directly, unlike a separate private method.
  • Expression-bodied members (=>) offer a concise syntax for simple methods and switch expressions alike.
Try it yourself

Write a method Describe(int temperature) using a switch expression with relational patterns to return "freezing", "cool", "warm", or "hot", and call it in a foreach loop over an array of sample temperatures. Then write a second method using params to accept any number of ints and return their average, and call it with a TryParse-based loop that reads numeric strings and skips any that fail to parse.
