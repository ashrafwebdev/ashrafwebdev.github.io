CSS Grid for two-dimensional layout

CSS · part of the free zero-to-hero guide

Builds on: Flexbox for one-dimensional layout

CSS Grid handles rows and columns simultaneously, making it the right tool for full page layouts, image galleries, and card grids — anywhere Flexbox's one-dimensional model starts to feel like a workaround involving nested flex containers just to get alignment across both axes.

grid-template-columns defines the column tracks. The fr unit (a fraction of remaining space) distributes leftover room proportionally, and repeat() avoids writing the same track definition over and over — repeat(3, 1fr) is identical to writing 1fr 1fr 1fr.

repeat(auto-fit, minmax(200px, 1fr)) builds a genuinely responsive grid without a single media query: the browser fits as many 200px-minimum columns as will comfortably fill the row, stretching them to share any leftover space. Swapping auto-fit for auto-fill keeps empty tracks reserved (useful when you want consistent column widths even with few items) rather than letting existing items stretch to fill the row.

Placing a child across multiple tracks uses grid-column/grid-row with either explicit line numbers (grid-column: 1 / 3) or the span keyword (grid-column: span 2), which is usually more resilient to adding or removing tracks later since it doesn't hardcode absolute line positions.

grid-template-areas lets you name regions of the grid and assign children to them by name via grid-area, which reads almost like a diagram of the layout directly in the CSS — genuinely useful for readability on non-trivial page structures like header/sidebar/main/footer.

Grid and Flexbox aren't rivals — a real page very often nests both: Grid defines the big page-level regions, and Flexbox arranges the content inside individual cells (like a card's header, body, and footer row).

styles.css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* @media conditionally applies CSS at a given viewport width — the full
   syntax is covered in the next lesson; here it just swaps the column
   count below 600px. */
@media (max-width: 600px) {
  .gallery { grid-template-columns: 1fr; }
}
styles.css (responsive grid with zero media queries)
.gallery-auto {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}

.gallery-auto .featured {
  grid-column: span 2; /* spans two tracks, resilient to column count changing */
}
styles.css (named areas for a page layout)
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "sidebar header"
    "sidebar main";
}
.sidebar { grid-area: sidebar; }
.header  { grid-area: header; }
.main    { grid-area: main; }
Key points
  • display: grid plus grid-template-columns/rows defines the tracks.
  • repeat(auto-fit, minmax(200px, 1fr)) builds a responsive grid with zero media queries.
  • auto-fit lets existing tracks stretch into empty space; auto-fill preserves empty tracks — pick based on whether you want items to stretch with few of them.
  • grid-column/grid-row on a child lets it span multiple tracks, using either line numbers or the more resilient span keyword.
  • grid-template-areas reads like a diagram of the layout directly in the CSS, which is a big readability win for non-trivial pages.
  • Grid and Flexbox aren't rivals — a Grid layout very often contains Flexbox-arranged content inside its cells.
  • The fr unit distributes leftover space proportionally after fixed-size tracks are accounted for.
Try it yourself

Build a 3-column responsive image gallery with CSS Grid that collapses to 1 column under 600px using @media (max-width: 600px) { ... } (the full media query syntax is covered in the next lesson, but this one line is enough to get started). Then rebuild the same gallery using repeat(auto-fit, minmax(...)) instead of the media query, and compare how each behaves as you resize the browser continuously rather than at a single breakpoint.
