01 Zero stage

Reading input and printing output

Python · part of the free zero-to-hero guide

Builds on: Lists, dictionaries, tuples, sets

print() writes to standard output, and accepts multiple arguments separated by commas, joined with a space by default. input(prompt) displays the prompt, pauses execution, and reads a single line of text typed by the user, always returning it as a string — even if the user typed digits.

f-strings (f"...") are the modern, preferred way to embed variables and expressions directly inside a string, replacing older %-formatting and .format() styles. Anything inside the curly braces is a real Python expression, not just a variable name — you can call a method, index into a list, or do arithmetic right there.

f-strings also support a format-spec mini-language after a colon: f"{price:.2f}" formats to two decimal places, f"{count:,}" adds thousands separators, and f"{value:>10}" right-aligns within a 10-character field — genuinely useful for lining up tabular console output.

Because input() always returns a string, converting it before doing arithmetic is not optional: int(input(...)) or float(input(...)) is the normal pattern, and both raise a ValueError if the text isn't actually a valid number. A later lesson covers try/except in full, but here's a quick preview of the shape: wrapping the risky line in try: and handling the failure in except ValueError: lets your program respond with a friendly message instead of crashing.

print() takes two often-overlooked keyword arguments: sep controls what goes between multiple printed values (default is a single space), and end controls what's printed after everything else (default is a newline) — setting end="" is the standard way to build up output on one line across multiple print calls.

For anything beyond quick console scripts, the built-in logging module is a better fit than scattering print() calls everywhere — it supports severity levels, timestamps, and can be redirected to a file, none of which plain print() gives you for free.

io_basics.py
name = input("What's your name? ")
age_text = input("How old are you? ")
age = int(age_text)  # input() always returns a string -- convert explicitly

print(f"Hello, {name}! In 10 years you'll be {age + 10}.")
formatting.py
price = 1234.5
quantity = 3

print(f"Total: ${price * quantity:,.2f}")   # Total: $3,703.50

for i in range(3):
    print(i, end=" -> ")
print("done")   # 0 -> 1 -> 2 -> done
safe_input.py
def read_int(prompt):
    while True:
        text = input(prompt)
        try:
            return int(text)
        except ValueError:
            print(f"'{text}' isn't a whole number, try again.")

age = read_int("How old are you? ")
print(f"You are {age} years old.")
Key points
  • input() always returns a string — convert with int()/float() before doing math on it, and expect a ValueError on bad input.
  • f-strings support arbitrary expressions, not just variable names: f"{price * 1.1:.2f}" both computes and formats in one place.
  • The format-spec after the colon controls decimals (.2f), thousands separators (,), and alignment/width (>10).
  • print(a, b, sep=", ") customizes the separator between multiple printed values.
  • print(..., end="") suppresses the automatic trailing newline, letting you build a line across several print calls.
  • Wrap numeric conversions from input() in try/except ValueError whenever the user might type something unexpected — a preview of a pattern the error-handling lesson covers in full.
  • The logging module is the better tool once a script grows beyond quick, throwaway console output.
Try it yourself

Write a script that asks the user for two numbers via input(), converts them to floats, and prints their sum, difference, and product, each formatted to two decimal places using an f-string format spec. Then wrap the conversion step in a try/except (mirroring the safe_input.py pattern above -- you'll cover try/except properly in a later lesson) so the script prints a friendly error instead of crashing if the user types something that isn't a number.
