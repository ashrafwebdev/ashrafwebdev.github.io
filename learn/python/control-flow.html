Control flow: if/elif/else, loops

Python · part of the free zero-to-hero guide

Builds on: Syntax, variables, and data types

Conditionals in Python read almost like English: if condition:, elif other_condition:, else:. Blocks are defined purely by indentation under each clause — there's no end keyword or closing brace, so a misplaced indent silently changes which statements belong to which branch.

for loops iterate directly over a sequence's items, not a numeric index by default the way loops in many other languages work — range(start, stop, step) generates a sequence of numbers when you do need a counted loop, and enumerate() gives you both the index and the value at once without manual bookkeeping.

while loops repeat as long as a condition stays true, which makes them the right tool when you don't know in advance how many iterations you'll need — reading input until the user types 'quit' is a classic example. Forgetting to update the condition inside the loop body is the most common way to accidentally write an infinite loop.

break exits the nearest enclosing loop immediately, while continue skips the rest of the current iteration and moves on to the next one. Both work identically in for and while loops, and both only affect the single loop they're written inside — not any outer loop it's nested within.

A lesser-known feature: both for and while loops can have an else clause, which runs only if the loop finished naturally without hitting a break. It's underused, but genuinely handy for search-style loops where you want to know whether a match was found.

Python has no traditional switch statement before 3.10 — a chain of elif or a dictionary mapping values to functions typically fills that role. Python 3.10 added match/case, structural pattern matching that goes well beyond a simple switch, letting you match on the shape of a value, not just equality.

control_flow.py
scores = [72, 88, 95, 60]

for score in scores:
    if score >= 90:
        print(score, "— A")
    elif score >= 70:
        print(score, "— B")
    else:
        print(score, "— needs work")
loop_tools.py
names = ["Amina", "Yusuf", "Chen"]

for i, name in enumerate(names, start=1):
    print(f"{i}. {name}")

target = "Chen"
for name in names:
    if name == target:
        print("found it")
        break
else:
    print("not found")   # runs only if the loop never broke
match_case.py
def describe(status_code):
    match status_code:
        case 200 | 201 | 204:
            return "success"
        case 404:
            return "not found"
        case code if code >= 500:
            return "server error"
        case _:
            return "other"

print(describe(201), describe(404), describe(503))
Key points
  • Blocks are defined entirely by indentation — no braces, no end keyword, so an indentation mistake changes program behavior silently.
  • for item in sequence: iterates over values directly; use enumerate(sequence) when you also need the index.
  • range(5) produces 0 through 4 — the end value is exclusive; range(1, 10, 2) adds a start and a step.
  • break exits the loop entirely; continue skips to the next iteration; both apply only to the innermost loop.
  • A for/while loop's else clause runs only when the loop completes without a break — useful for search patterns.
  • Watch out for infinite while loops: the condition must eventually become false, so make sure the loop body actually updates whatever it checks.
  • Python has no switch statement before 3.10; a chain of elif or a dict lookup fills that role in older code.
  • match/case (3.10+) supports structural pattern matching, guard clauses, and a catch-all case _:, going well beyond simple equality checks.
Try it yourself

Write a for loop over a list of numbers that prints whether each is even or odd using if/else. Then write a second loop that searches the same list for a specific target value, using break when it's found and the loop's else clause to print a message when it isn't.
